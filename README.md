# countpage

Count structured JSON page payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/countpage/

## Install / run

```bash
git clone https://github.com/theworker02/countpage.git
cd countpage
node src/cli.js
node --test
```
